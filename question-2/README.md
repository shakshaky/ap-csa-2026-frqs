## My Approach

I was instructed to create a full ```Bottle``` class with constructors, and a method called ```updateAmount()``` containing a ```double``` parameter.

## Course Connections

This question reminded me of the **Whack-A-Mole (Object Oriented) Project** I did, where I had to use ```formula <= diameter / 2``` in order to create a proper circular hitbox, that chnaged position whenever it was clicked.

## What Gave Me Trouble

My mistake was that I kept setting the bottle amount to the max capacity everytime the ```updateAmount()``` method was used.

## What I Would Do Differently

I set the amount to the max capacity in the ```Bottle``` constructor to answer the question fully,
and avoid setting the amount to the maximum amount every single time.
